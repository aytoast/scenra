# ARDY CoreSkin asset

core-skin.bin is browser-oriented conversion of NVIDIA ARDY ardy/assets/skeletons/cskel27/skin_standard.npz.

Source repository: nv-tlabs/ardy
Source commit: 693f74d13b3d04a0a22ce127ee79c929dd89756b
Conversion: float32 bind vertices and normals, uint32 faces, bind transforms, inverse bind transforms, LBS indices, and LBS weights.
